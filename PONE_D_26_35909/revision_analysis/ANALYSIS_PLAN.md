1. Preserve the initial submission snapshot. New results go in this revision directory.
2. TGFB2 is the requested endpoint. For the existing-label and uniform-marker analyses separately, compute each cohort's mean within-patient AC-minus-other contrast and variance s²/n. The primary scale is mean log1p library-normalized expression, not log2 fold change. Pool cohorts with >=3 eligible patients by REML. Use modified Knapp–Hartung intervals (variance scale at least 1; t with k−1 df) and also report ordinary KH sensitivity. Report effect, CI, Q, tau², weights and prediction intervals. No meta-regression or publication-bias tests with so few cohorts.

## Documented follow-up after first sensitivity results

The first run showed that reassigning uniform states after normalization to 1,000 counts, or restricting mitochondrial fraction to 5%, removed GSE162631 from inferential pooling because AC-like groups fell below 20 cells. To separate expression-scale effects from label/eligibility changes, add a fixed-uniform-label arm using the submitted-expression uniform assignments, with the same normalization/QC scenarios. This is an explicitly post hoc diagnostic; it does not replace or select among the original sensitivity results. Source-count audit also evaluates agreement with pre-existing original Tumor/Prol.tumor annotations; no new marker or CNV cutoff is chosen from TGFB2 expression.
