# Recoded PLOS ONE release

Patient identifiers are sequential within cohort (P1, P2, ...), consistent across S9-S14 and both code packages. Spatial sections use patient-linked sequential codes. Cell barcodes have been replaced by C1, C2, ... within each minimal input. Original identifiers and the private crosswalk are not included. Numeric analysis values and minimal expression matrices are unchanged.

The original source-reading scripts require separately acquired public inputs. For the Greenwald input route, provide general/sample_metadata.csv using the schema in input_templates/greenwald_sample_metadata.csv and correspondingly coded matrix filenames. The archived snRNA notebook now reads sample_info.csv and snrna_sample_info.csv from its local input folder instead of embedding clinical dictionaries. These are provenance workflows; the full upstream inputs are not supplied. The original-label tables and figures can be reproduced from the supplied minimal inputs and source tables; full count-level revision analysis requires the larger retained-count objects documented in the revision package.

Patient coding is study-local pseudonymization of derived public data, not a claim that the underlying source repositories have been altered. Anatomical tumor regions and analytical spatial coordinates needed for reproduction are retained.

## Full analysis and external validation

Install the Python dependencies from the repository root and the Poppler commands `pdfinfo` and `pdftocairo`. The Greenwald spatial analysis uses R with `jsonlite` and `pdftools` (with Poppler support). The optional CPTAC download route uses `curl`. Source-level scripts 01–05 and 11 use `PUBLIC_INPUT_ROOT` for the directory containing `raw_inputs`, `processed_inputs` and `upstream_source`. Use a fresh `PUBLIC_ONLY_PACKAGE` for outputs. Point `GLIOMA_VALIDATION_ROOT` to the project parent when working with the original source layout.

Stages 06–10 accept paths to the spatial and protein inputs separately. For Greenwald, supply a sample metadata CSV whose sample names exactly match the matrix and spot-label filenames. For CPTAC phosphoproteomics, `--input-file` selects the local matrix. For GSE253080, stage 09 selects a representative TGFB2 section using the central rank or ranks of the adjusted correlations. When candidate sections tie, it uses the first in the original metadata order. Across the 16 GSE253080 sections, this selects the 2,449 spots in the archived plotting table used by the submission renderer. The earlier external-validation PDF shows the other central section with 1,428 spots. Patient-level statistics use all eligible sections. The input requirements and output tables are listed at the top of each script. The release's minimal H5ADs, aggregate CSVs and manuscript workbooks supply the inputs for the lightweight reproduction routes.
